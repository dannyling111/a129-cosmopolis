# CosmoPolis · 量化积木城市

A129 独立仓库网页：先定功能，再切区域，再把零件自由组合。客厅是母模板，人物按场景互动。

- 量化沙盘（真跑一遍五层）：https://dannyling111.github.io/a129-cosmopolis/studio.html
- 仓库：https://github.com/dannyling111/a129-cosmopolis

## 这一版做了什么

工作指引说的五层——**社区 → 功能 → 区域 → 套件 → 人物**——已经写成可运行的引擎，
落地顺序里的第 0–4 步全部进代码；指引页面的数字不再是手写的，而是实时从引擎读出来的。

- **48 种功能 · 6 族**：住 / 作 / 食 / 市 / 聚 / 服，名字逐字照指引原表
- **12 大类套件**：座具 / 桌案 / 睡眠 / 收纳 / 厨作 / 餐吧 / 灯具 / 织物 / 绿植 / 媒介 / 建筑 / 人物
  （第 12 类「人物」是 12 个动作，不是家具——这是「人物是套件，不是装饰」那句话的字面落实）
- **5 个区域角色**：窗墙 / 主区 / 辅区 / 墙装 / 通行；**4 套布置程序**：会客朝向 / 靠墙沙发 / 侧向围坐 / 阅读角落
- **社区规则**：层带、相邻、对外比例、街道，在**抽房间的时候**生效，不是抽完再装饰

## 怎么玩（手机竖屏，全触控）

1. 一根手指拖 = 转；两根手指捏 = 远近
2. **点一间房** → 「房」页列出它五块区域各放了什么
3. 「区域」页点平面上任意一块 → 看这一块**允许**什么（同类可互换、跨类不许进）、这一间**实际**抽到了什么
4. 「人物」页 → 这个功能的人物脚本，和这一间真长出来的人
5. 「体检」页 → 逐条量化判据：越界 / 挡路 / 跨类 / 层带 / 相邻，全绿才算数
6. 换种子 = 换一座城；同一个种子永远长出同一座城

## 目录

```
engine/     纯数据 + 纯函数，没有任何依赖，可被别的项目直接 import
  SCHEMA.md   数据契约（唯一权威源，改数据先改它）
  rng.mjs     稳定随机（同种子同结果）
  zones.mjs   第 2 层：把一间房切成五块 + 4 套布置程序
  kits.mjs    第 3 层：12 大类套件库
  functions.mjs 第 1 层：48 功能 × 区域程序
  people.mjs  第 4 层：48 份人物脚本
  actors.mjs  人物运行时（坐/走/忙）
  city.mjs    第 0 层：层带 / 相邻 / 街道规则
  building.mjs assemble()：按社区规则抽整栋楼
  room.mjs    planRoom()：功能 → 区域 → 套件
view/       渲染与操作（three.js），不做任何决策
tests/      机器闸：engine_check.mjs（引擎）· page_check.mjs（真手机真触摸）
```

## 本地跑

```bash
python3 -m http.server 8099          # 然后打开 http://127.0.0.1:8099/studio.html
node tests/engine_check.mjs          # 引擎体检，退出码 2 = 不许上线
node tests/page_check.mjs http://127.0.0.1:8099/studio.html   # 手机可用性体检（需要 playwright）
```

纯静态页面，无构建步骤，打开即可。
