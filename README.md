# CosmoPolis · 量化积木城市

A129 独立仓库网页：先定功能，再切区域，再把零件自由组合。客厅是母模板，人物按场景互动。

## 线上地址

- 工作指引：https://dannyling111.github.io/a129-cosmopolis/
- 仓库：https://github.com/dannyling111/a129-cosmopolis

这一版只发布工作指引，不改三维引擎。功能从 14 种扩到 48 种，套件收成 12 大类约 120 个零件。

## 怎么读

1. 五层：社区 → 功能 → 区域 → 套件 → 人物
2. 点客厅平面上的区域，看这一块允许什么
3. 换布置程序，看区域角色怎么换，零件语法不变
4. 落地顺序：先客厅进引擎，再克隆卧室 / 厨房 / 咖啡 / 书房

纯静态页面，打开即可。
